# 📧 Spam Mail Detector

## 📌 Objective

The objective of this project is to classify SMS messages as **Spam** or **Ham (Not Spam)** using Natural Language Processing (NLP) and Machine Learning.

---

## 🗂️ Dataset

- Dataset: SMS Spam Collection
- Source: Kaggle / UCI Machine Learning Repository
- Number of Messages: 5572

---

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

---

## 🤖 Machine Learning Algorithm

- Multinomial Naive Bayes

---

## 📋 Workflow

1. Import Libraries
2. Load Dataset
3. Explore Data
4. Encode Labels
5. TF-IDF Vectorization
6. Train-Test Split
7. Train Naive Bayes Model
8. Prediction
9. Evaluation

---

## 📊 Results

| Metric | Value |
|--------|-------|
| Algorithm | Multinomial Naive Bayes |
| Accuracy | **96.86%** |

---

## 🎯 Conclusion

The Spam Mail Detector successfully classified SMS messages into Spam and Ham using TF-IDF Vectorization and the Multinomial Naive Bayes algorithm, achieving **96.86% accuracy**.
