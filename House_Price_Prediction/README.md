# 🏠 House Price Prediction

## 📌 Objective

Predict house prices using machine learning based on features such as area, bedrooms, bathrooms, parking, and furnishing status.

---

## 🗂️ Dataset

- Dataset: Housing Prices Dataset
- Source: Kaggle

---

## 🛠️ Technologies Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 🤖 Machine Learning Algorithm

- Linear Regression

---

## 📋 Workflow

1. Import Libraries
2. Load Dataset
3. Explore Data
4. Data Visualization
5. One-Hot Encoding
6. Train-Test Split
7. Train Linear Regression Model
8. Prediction
9. Model Evaluation

---

## 📊 Results

| Metric | Value |
|--------|-------|
| Algorithm | Linear Regression |
| R² Score | **0.65** |

---

## 🎯 Conclusion

A Linear Regression model was developed to predict house prices. The model achieved an **R² Score of 0.65**, showing good predictive performance for this beginner-friendly dataset.
